# Poster / flyer

A one-page A3 portrait poster/flyer summarising the Open TechEd NanoDrop pilot for a general audience: the problem, what we did, the outcome, why it matters, and the acknowledgement.

**[OSE_poster_v1.0.pdf](OSE_poster_v1.0.pdf)**

- **Authors:** J. van Leeuwen, V. de Boer, V. Saggiomo
- **Format:** one page, A3 portrait
- **Version:** v1.0

> The QR code and repository URL printed on the poster point to the original demonstration repository ([vcjdeboer/nanodrop-pylabrobot-demo](https://github.com/vcjdeboer/nanodrop-pylabrobot-demo)). This repository is the project home, bundling the reports, the initial script, and that demonstration.
